Руководство пользователя

Добро пожаловать в систему управления складскими остатками! Здесь вы найдете инструкции по работе с разделами системы в зависимости от вашей роли.

1. Для кладовщика

  • Справочник товаров: Нажмите кнопку «Добавить товар», чтобы внести новую позицию. Укажите название, категорию, остаток и минимальный запас. Если товара станет меньше минимума, система подсветит его красным. Товары можно удалять (кнопка-корзина).
  • Заявки преподавателей: Здесь отображаются заявки от учителей. Нажмите «Выдать», если товар есть, или «Отклонить», если его нет. Если нажали случайно — используйте кнопку «Вернуть».
  • Отчеты: Просмотр статистики и имитация скачивания отчета в Excel.

2. Для преподавателя

  • Просмотр склада: Проверьте, какие товары есть в наличии. Редактировать их нельзя.
  • Подать заявку: Выберите нужный товар из списка, укажите количество и нажмите «Отправить». Заявка мгновенно попадет к кладовщику.

3. Для руководства

  • Общие отчеты: Сводная статистика по расходам и операциям за период.
  • Сотрудники: Список всех пользователей системы с их ролями и статусами.

Тестовые аккаунты

Для проверки работы используйте следующие данные:

  • Кладовщик: admin / 1234
  • Преподаватель: teacher / 1234
  • Руководство: boss / 1234
